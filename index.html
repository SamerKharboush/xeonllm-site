Built for one machine: yours

Everything below runs locally. The only thing that leaves your Mac is the model download.

  • A chat that stays out of the way

    Persistent conversations, full Markdown with one-click code copy, live tokens per second, attachments and vision, conversation forking and per-message metrics.

  • Models picked for your hardware

    The app reads your GPU and RAM, then estimates how each model will actually run before you download it. Curated catalog plus Hugging Face search.

  • Agent tools and MCP

    The model can read, edit and run files with per-step permission, run JavaScript in a sandbox, and use tools from Model Context Protocol servers you connect.

  • An OpenAI-compatible server

    A local endpoint at 127.0.0.1:8080, router mode that loads whichever model a request names, and several independent servers at once — one per GPU if you want.

  • Every GPU you have

    Split a model across cards by layer or by tensor, including external GPUs, with weights kept in VRAM. MoE-aware offload sizes itself to the card you own.

  • Measured, not guessed

    A built-in benchmark runs prompt and generation tests per configuration and charts them side by side, so you can find the sweet spot for your card.

Questions people actually ask

Does it run on Apple Silicon?

The current build is x86_64 only. On an Apple GPU the AMD-specific Metal work never enters the picture, so an Apple Silicon Mac needs a different build; this fork's fixes target Intel Macs with discrete AMD graphics.

What Mac do I need?

macOS 14 or later on an Intel Mac with a discrete AMD GPU. The machine the fork is measured on is a Mac Pro (Late 2013): Xeon E5-2697 v2, 64 GB of RAM and two FirePro D700. Cards with 8 GB or more are the comfortable range; the app tells you what fits before you download.

Do my chats leave the machine?

No. Inference runs on your GPU and your CPU. The server binds to localhost by default; LAN access is a setting you have to turn on deliberately.

Can I use it from another app?

Yes. It speaks the OpenAI API on 127.0.0.1:8080, and router mode loads whichever model each request names, so coding assistants can switch models without a restart.

How big are the models?

From about 1 GB for a 1B model at 4-bit to 11 GB for a 35B mixture-of-experts at 4-bit. The model manager shows a VRAM and RAM estimate for your hardware next to each entry.

Where does the download come from?

GitHub Releases on this repository. Builds are ad-hoc signed rather than notarised, so the first launch means right-clicking the app once and choosing Open.
